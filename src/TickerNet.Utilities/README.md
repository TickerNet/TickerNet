# TickerNet.Utilities

Shared entities, enums and helper types for [TickerNet](https://github.com/TickerNet/TickerNet), an open-source job scheduler for .NET.

## Install

```bash
dotnet add package TickerNet.Utilities
```

Most apps get this package transitively through `TickerNet` or a store package, so you usually do not need to install it directly.

## Usage

`TickerNet.Utilities` holds the types shared by the scheduler and its providers, including the ticker entity and interface definitions. Refer to the [getting started guide](https://tickernet.github.io/TickerNet/getting-started.html) for adding jobs and choosing a store.
