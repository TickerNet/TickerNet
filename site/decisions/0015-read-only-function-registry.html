ADR 0015 · Public API

Make the ticker function registry read-only

TickerFunctionProvider exposed its three registries as public, writable static fields. They are now properties with a private setter, so registration can only go through the provider's methods.

Status
Accepted
Decided
2026-11-24
Affects
TickerFunctionProvider (public API)

Related: ADR 0006 version independently, ADR 0009 self-hosted Hub and remote workers

01

Context

TickerFunctionProvider.TickerFunctions, TickerFunctionRequestTypes and TickerFunctionRequestInfos were public static fields. The source generator writes them once at startup, and the Hub rewrites the remote slice through MergeRemoteFunctions, but any other code could assign a whole new dictionary at any time. A registry swapped after scheduling starts is hard to trace: jobs disappear or point at delegates from another assembly, and no log line says why.

02

Decision

  • The three registries are properties with a public getter and a private setter. Callers read them exactly as before.
  • Registration keeps its existing entry points: RegisterFunctions, ReplaceFunctions, MergeRemoteFunctions and the request-type and request-info equivalents. No new mutation path is added.
  • A unit test asserts each member is a property whose setter is private, so a field cannot quietly return.
03

Alternatives considered

  • Leave the fields public. Rejected: the Hub and the generator already have methods that preserve invariants; a second, unchecked write path only exists by accident.
  • Internal setters plus InternalsVisibleTo. Rejected: the Hub is a separate package, so this would widen internals to another assembly and still allow replacement.
  • Expose a wrapper object with its own lock. Rejected for now: it changes every read site for a problem the private setter already solves.
04

Consequences

  • This is a public API change: code that assigned one of the three fields no longer compiles. That code was replacing the scheduler's registry, so the break is deliberate and belongs in the release notes for the next major version.
  • The source generator, the Hub, the dashboard and every persistence provider keep working through the existing methods and reads.
  • Tests that need an empty registry call ReplaceFunctions with an empty dictionary, not an assignment.
05

Where it lives
