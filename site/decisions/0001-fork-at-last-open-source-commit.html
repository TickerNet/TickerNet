ADR 0001 · Origin and license

Fork TickerQ at its last open-source commit

TickerNet starts from TickerQ commit 3acd0f31 (5 July 2026), the last commit on TickerQ's main branch licensed MIT OR Apache-2.0, and keeps TickerQ's history up to it.

Status
Accepted
Decided
2026-11-23
Affects
NOTICE, LICENSE, git history

Related: ADR 0002 Name the project TickerNet and rename everything, ADR 0003 License MIT OR Apache-2.0 with an open-source pledge and no CLA, ADR 0004 Keep a clean room around TickerQ's commercial versions

01

Context

TickerQ, by Arcenox LLC, was dual-licensed MIT OR Apache-2.0. Its LICENSE at commit 3acd0f31 says so, and the TickerQ 10.4.0 NuGet package, built from commit c6ed1e7 (12 May 2026), carries the license expression MIT OR Apache-2.0.

On 19 October 2026, commit 13a9b544, "Main commercial (#919)", moved TickerQ's main branch to a commercial license. TickerQ 10.5.0, released on 25 October 2026, ships LICENSE.md: the TickerQ Software License Agreement v1.0. It is free for organizations under US$5 million in annual revenue and paid above that. Section 2 of the agreement says artifacts released earlier under MIT or Apache-2.0 stay under their original licenses.

So TickerQ's code up to the relicense can be forked under its open-source license, and nothing after it can.

02

Decision

  • Fork at 3acd0f314a351817a3159d7d29a3798c8612a263 (2026-07-05), the last commit on TickerQ's main branch distributed under MIT OR Apache-2.0.
  • That commit is four commits after the 10.4.0 package. The four are: #866, which moves ActivitySource diagnostics into the main package (5ffa80a); #859, which bumps OpenTelemetry to the CVE-patched 1.15.3 (a4600eb); #864, a refactor of cron occurrence serialization (526d4fe); and #874, the MongoDB persistence provider by Alex Brown (3acd0f3).
  • Keep TickerQ's git history up to the fork point, 434 commits, so every original change keeps its author.
  • Record where the code came from in NOTICE and at the top of LICENSE, and keep Arcenox LLC's copyright notices.
03

Alternatives considered

  • Fork exactly the 10.4.0 package source (c6ed1e7). Rejected: it would lose the OpenTelemetry CVE fix and the MongoDB provider.
  • Stay on TickerQ under its Community license. It is free under US$5 million in annual revenue, but it is source-available, not open source.
  • Use an existing community fork, such as xaviergxf/Tickwork (MIT, forked from 10.4.0 on 2026-10-23). Why it was not chosen: Not recorded.
04

Consequences

  • TickerNet has everything TickerQ had at 3acd0f31, including the MongoDB store and ActivitySource tracing in the core packages.
  • Nothing from TickerQ 10.5.0 or later can come in. Fixes and features made there have to be written again from a description (ADR 0004).
  • The repository's history starts with TickerQ's commits. TickerNet's own work starts at commit 08b7fff.
