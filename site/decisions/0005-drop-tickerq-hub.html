ADR 0005 · Code and packages

Drop the TickerQ Hub integration

The client SDKs and remote executor for TickerQ Hub, a hosted service with its own terms, are removed, along with upstream-only CI and files. Hooks for them left in src/ are a follow-up.

Status
Amended 2026-11-23: the hooks listed under Decision are kept and generalised, not removed, and remote execution returns without TickerQ Hub through ADR 0009.
Decided
2026-11-23
Affects
hub/ (removed), .github/workflows/, src/TickerNet.Utilities, src/TickerNet

Related: ADR 0001 Fork TickerQ at its last open-source commit, ADR 0006 Version independently and target .NET 10 only, ADR 0009 Run jobs on remote workers through a self-hosted hub

01

Context

At the fork point the repository held hub/: the .NET TickerQ.SDK and TickerQ.RemoteExecutor, and a Node SDK. They connect to TickerQ Hub, a hosted service with its own terms. The repository also had upstream workflows for builds, pull requests, NuGet publishing, the CLA and syncing version branches, which need upstream secrets.

02

Decision

  • Commit 302fc65 removed hub/: TickerQ.SDK, TickerQ.RemoteExecutor and the Node SDK, and their InternalsVisibleTo entries in TickerNet.Utilities.
  • It also removed the upstream workflows (build.yml, pr.yaml, publish.yml, cla.yml, sync-version-branches.yml), CLA.md, FUNDING.yml, .sync-exclude, .sync-overrides, the upstream package icon icon.jpg, and a Vite cache committed by mistake.
  • Hooks for the Hub stay in src/ for now. Removing or generalising them is a follow-up:
    • SdkOfflineSkipException, thrown by TickerExecutionTaskHandler when a function named name@node has no local delegate.
    • TickerFunctionProvider.FunctionNodeResolver, ResolveNodeName, ReplaceFunctions, ReplaceRequestInfo, MergeRemoteFunctions and MergeRemoteRequestInfo, whose comments describe the remote executor's sync with the Hub.
    • CronTickerEntity.IsSystemPaused, set by the removed worker-stream monitor, with its EF Core column and the filters on it in the EF Core, MongoDB and in-memory stores.
    • The internal Retries and RetryIntervals on TickerFunctionContext, forwarded for a remote-dispatch delegate, and comments about SDK and remote-executor cron jobs in the stores.
03

Alternatives considered

Not recorded.

04

Consequences

  • Without the TickerQ Hub clients, TickerNet had no remote execution: a job ran only in a process that registered its function. Amended 2026-11-23: ADR 0009 adds remote workers through TickerNet.Hub and TickerNet.Worker, with no hosted service.
  • Some hooks are public API, and IsSystemPaused is a database column. Removing them changes the public API and, for the column, the schema, so it needs its own ADR (AGENTS.md, Public API). Amended 2026-11-23: they are kept. SdkOfflineSkipException is now an obsolete subclass of WorkerOfflineException. The TickerFunctionProvider members and the internal Retries and RetryIntervals stay, and TickerNet.Hub uses MergeRemoteFunctions, MergeRemoteRequestInfo, the IsSystemPaused column and the function@node naming rule.
  • TickerNet has its own CI: ci.yaml, dco.yaml and pages.yaml.
