ADR 0002 · Code and packages

Name the project TickerNet and rename everything

The fork is called TickerNet. Every TickerQ name in the code, the packages and the diagnostics became TickerNet. Stored names did not contain TickerQ, so existing data carries over.

Status
Amended 2026-11-23: some external names changed by the rename keep working under their TickerQ names, as listed in ADR 0010.
Decided
2026-11-23
Affects
src/, tests/, samples/, benchmarks/, TickerNet.slnx

Related: ADR 0001 Fork TickerQ at its last open-source commit, ADR 0003 License MIT OR Apache-2.0 with an open-source pledge and no CLA, ADR 0010 Accept TickerQ's names where moving would otherwise break

01

Context

The fork needs its own name. TickerQ is Arcenox LLC's name (TRADEMARKS.md), and TickerQ's commercial agreement restricts use of its trademarks in sections 8(i) and 14. People moving from TickerQ also need their stored jobs to keep working.

02

Decision

  • The project is called TickerNet.
  • Commit 4d93c34 replaced TickerQ with TickerNet in namespaces, package IDs, project and file names, types and members, in every letter case. It changed source-generator diagnostic IDs from TQ0nn to TN0nn. Nothing else in the code changed.
  • Names that start with TickerQuery or contain TickerQueryable, such as ITickerQueryable and TimeTickerQueryFilter, were kept. They mean "ticker query", not the product.
  • Stored names were left alone: the EF Core schema ticker and its tables, the MongoDB ticker_ collections and the Redis tq: keys. EF Core databases, MongoDB collections and Redis data carry over.
03

Alternatives considered

  • Keep TickerQ's namespaces and package IDs for drop-in compatibility. Rejected: TickerQ is Arcenox LLC's name, it invites confusion between the two projects, and TickerQ's commercial agreement restricts use of its trademarks in sections 8(i) and 14.
  • TickerR. Rejected: it is one letter away from TickerQ and likely to be confused with it.
04

Consequences

  • Moving from TickerQ needs code changes: package references, namespaces, renamed API and diagnostic IDs. The migration guide lists them.
  • Because the rename covered every letter case, some external names changed too: the default dashboard path, the Redis InstanceName default and keyed-service key, the ActivitySource, span and tag names, log text and the dashboard's browser storage keys. Monitoring, proxies and bookmarks that use them need updating. Amended 2026-11-23: old dashboard links now redirect, saved dashboard sign-ins carry over, and TickerQ trace names are available on request (ADR 0010).
  • TRADEMARKS.md keeps the new name for the open-source project.
05

Where it lives

  • Namespaces and package IDs across src/*/
