ADR 0008 · Docs and process

Publish the docs as a static site on GitHub Pages, with an ADR log

The docs are plain HTML in site/, uploaded to GitHub Pages with no build step. Architecture decisions are recorded in site/decisions/.

Status
Accepted
Decided
2026-11-23
Affects
site/, .github/workflows/pages.yaml

Related: ADR 0007 Omniscient AI sponsors TickerNet, which lives in its own GitHub organization

01

Context

TickerNet needs docs for users and contributors, and a record of why it is built the way it is. Both should live next to the code and change in the same pull requests.

02

Decision

  • Docs are static HTML in site/, with no build step. .github/workflows/pages.yaml uploads site/ to GitHub Pages on pushes to main that touch site/ or the workflow, and on manual runs.
  • The site is a project site at https://tickernet.github.io/TickerNet/, so pages link to each other with relative links only.
  • Architecture decision records live in site/decisions/, with a template and an index.
  • The layout follows a pattern the sponsor uses for its own docs. Shared styles and scripts are in site/assets/. The only outside resources are Google Fonts and highlight.js from cdnjs.
  • Every page says when it was written and which branch it was checked against.
03

Alternatives considered

Not recorded.

04

Consequences

  • Docs changes are ordinary pull requests, reviewed with the code (CONTRIBUTING.md, items 4 and 5).
  • Nothing generates or checks the pages. Accuracy is kept by hand: a change that makes a page wrong fixes it in the same pull request, and AGENTS.md has a link check to run before pushing.
