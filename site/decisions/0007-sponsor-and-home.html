ADR 0007 · Origin and license

Omniscient AI sponsors TickerNet, which lives in its own GitHub organization

Omniscient AI sponsors and stewards TickerNet. The repository is TickerNet/TickerNet, in an organization of its own, so the whole project can be handed over in one step.

Status
Accepted
Decided
2026-11-23
Affects
GOVERNANCE.md, NOTICE, LICENSE, Directory.Build.props

Related: ADR 0003 License MIT OR Apache-2.0 with an open-source pledge and no CLA, ADR 0008 Publish the docs as a static site on GitHub Pages, with an ADR log

01

Context

Someone has to fund maintenance and hold the project's name, GitHub organization, docs site and NuGet package IDs. The pledge in GOVERNANCE.md says these must be transferable, as a set, to an open-source foundation or to the active maintainers.

02

Decision

  • Omniscient AI (Omniscient AI Private Limited) sponsors TickerNet and is its steward, as GOVERNANCE.md describes.
  • The README and every page of this site show Omniscient AI's logo and a "Sponsored by Omniscient AI" credit. The logo files in site/assets/sponsor/ come from Omniscient AI's brand assets; NOTICE and TRADEMARKS.md say they are Omniscient AI's trademarks and are not covered by the project license.
  • The repository lives at TickerNet/TickerNet, in its own TickerNet GitHub organization, separate from the sponsor's own repositories, so it can move to a foundation as a whole.
  • New work carries the copyright line "Omniscient AI Private Limited and the TickerNet contributors". Arcenox LLC's notices for the original work stay in LICENSE and NOTICE.
  • Package metadata: authors "Omniscient AI and the TickerNet contributors", company "Omniscient AI Private Limited", repository https://github.com/TickerNet/TickerNet, project site https://tickernet.github.io/TickerNet/.
03

Alternatives considered

Not recorded.

04

Consequences

  • A handover under pledge item 4 is one organization transfer plus the NuGet IDs.
  • Contributors keep the copyright in their work. The steward holds the name and package IDs for the project.
  • The sponsor credit is the name and a link to https://omniscient.to, nothing more (AGENTS.md, Sponsor privacy).
